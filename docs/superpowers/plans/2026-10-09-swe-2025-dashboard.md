# SWE 2025 Data Source, Source Switch, and Dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Point the SWE simulator at the 2025 population tab with a switch back to the legacy tab, and add a separate full-access dashboard that correlates Achievement 2025 with salary, nominal, seniority, age, and rating.

**Architecture:** A DOM-free stats module (`src/dashboard/js/stats.js`) holds all parsing and statistics, tested in Node. Both Apps Script backends (SWE `Code.gs` and new `dashboard/Code.gs`) read the new tab by header name, through identical blocks marked `BEGIN SHARED` / `END SHARED` that a test compares byte for byte. The SWE client gets a source selector; the dashboard is a new build target `--app=dashboard`.

**Tech Stack:** Node.js built-ins (build, harness, vm-based tests), Google Apps Script (`Code.gs`), Chart.js 4 (already loaded in `src/head.html`), ESLint (dev only).

**Spec:** `docs/superpowers/specs/2026-10-09-swe-2025-dashboard-design.md`

## Global Constraints

- Spreadsheet ID `1c2D9H4r6ZkWRchhNysoGjwnY0kn_m0tbpHQSlQVofRM`, tab `Copie de Liste Sales`, header on row 1, data from row 2.
- Row inclusion: only `In/Out` equal to `In` after trim, case-insensitive. Other values are ignored and counted.
- Required headers, matched after trim and case-insensitive: `Country`, `Business Title`, `In/Out`, `Annualized Base Pay`, `Nominal`, `Achievement 2025`, `Rating - Most Recent`, `Market`, `Category`, `seniority years`, `Age`.
- A valid row needs a non-empty country and job profile, a numeric fixed salary greater than 0, and a numeric nominal of 0 or more.
- Achievement 2025 is read from the display text (`105%` becomes 105). Non-numeric achievement excludes the row from achievement statistics only.
- Rating level: substring `P1` to `P5`, case-insensitive. No match gives `Unclassified`. Ordinal order P1 < P2 < P3 < P4 < P5.
- The dashboard is full access only (`canViewIndividualTables`). Restricted and both-list users are denied.
- `DEPLOYED_PROFILE` stays SWE. The browser never chooses a spreadsheet; the server accepts only the keys `swe2025` and `legacy`.
- NCE is unchanged. Its profile, remote project, and deployment do not change.
- No real data is committed. The CSV fixtures are synthetic.
- No deployment. Only the build and tests run in this plan.

## Review Focus

1. **Blank, `n/a`, or text achievement.** Row kept for the simulator and correlations, excluded from achievement statistics, counted, never `NaN`. Pinned in Task 1 (`achievementMissing` = 2, no NaN in means) and Task 2.
2. **`In/Out` variants (`out`, `OUT`, ` In`).** Only exact `In` after trim is used. Pinned in Task 1 (fixture rows 6 and 7).
3. **Non-numeric salary (`abc`).** Row ignored and counted as invalid, not treated as zero. Pinned in Task 1 (fixture row 12).
4. **Blank or unknown rating.** Goes to `Unclassified` and stays in the rating table. Pinned in Task 1 (fixture row 10).
5. **Renamed or missing header in the Sheet.** Explicit error naming the column, no partial load. Pinned in Task 2 and Task 3.

### Task 1: Synthetic fixture and pure stats module

**Files:**
- Create: `population_test_swe2025.csv` (repository root, synthetic)
- Create: `src/dashboard/js/stats.js`
- Create: `tests/dashboard-stats.test.js` (run directly, not through the UI harness)

**Interfaces:**
- Produces (all top-level functions in `stats.js`, pure):
  - `parseAchievementPercent(text: string) -> number | null`. Strips whitespace (including NBSP), a trailing `%`, and uses `.` as decimal separator after replacing `,`. Returns null for empty or non-finite.
  - `ratingLevel(label: string) -> 'P1'|'P2'|'P3'|'P4'|'P5'|'Unclassified'`
  - `RATING_LEVELS: ['P1','P2','P3','P4','P5','Unclassified']`
  - `binLabel(value: number | null, width = 5) -> string | null`. Gives `'0-4'`, `'5-9'`, and so on; null for null or non-finite.
  - `parseSwe2025Csv(text: string) -> { rows: Row[], counts: { total, notIn, invalid, achievementMissing } }`. Throws `Error('Missing column: <Original Name>')` when a required header is absent.
  - `pearson(xs, ys) -> number | null`, `spearman(xs, ys) -> number | null`. Both null when fewer than 3 pairs or zero variance. Spearman uses average ranks for ties.
  - `linearFit(xs, ys) -> { slope, intercept } | null`
  - `aggregateDashboard(rows: Row[], filters: { country, market, category }) -> Model`. Empty filter string means all.
  - `Row = { country, market, category, jobProfile, fixed, nominal, achievement: number|null, rating: string, seniority: number|null, age: number|null }`
  - `Model = { rowCount, achievementCount, meanAchievement, scatter: {x,y}[], trend: {slope,intercept,x0,x1}|null, byRating: {level,mean,n}[], bySeniority: {bin,mean,n}[], byAge: {bin,mean,n}[], correlations: {variable,pearson,spearman,n}[] }`. Correlation variables, in order: `'Annualized base pay'` (fixed), `'Nominal'`, `'Seniority'`, `'Age'`, `'Rating level'` (P1 to P5 as 1 to 5; Unclassified skipped).
